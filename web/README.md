# Where the centre holds — web map

Scrollytelling MapLibre map for the five LGA cities. Hosted on GitHub Pages from this `web/` folder.

**Live:** https://whizialfa.github.io/nigeria-urban-spread/

Basemaps are Esri World Gray / Streets / Imagery (no API key). Tiles are cache-busted. Story chapters take shareable `?chapter=` URLs. Embedded tour skips with `?tour=0` and does not nag after Skip.
